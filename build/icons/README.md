# Trinity Control application icons

This directory is reserved for official Trinity Control application icons.

Required source: a square, transparent, officially approved Trinity emblem at
1024×1024 or larger. The existing horizontal church wordmark is intentionally
not cropped, redrawn, or stretched into an application icon.

When approved artwork is supplied, generate:

- `png/16.png`
- `png/32.png`
- `png/48.png`
- `png/64.png`
- `png/128.png`
- `png/256.png`
- `png/512.png`
- `png/1024.png`
- `trinity-control.icns`
- `trinity-control.ico`
